# Doctor — عيادة نبض

واجهة عربية RTL متجاوبة لعيادة طبية، مبنية كصفحة ثابتة تعمل دون أدوات بناء أو تثبيت.

## تشغيلها محليًا

افتح `index.html` في المتصفح، أو شغّل خادم ملفات ثابتة في جذر المشروع.

## ما تتضمنه

- صفحة تعريفية بالعيادة والخدمات والفريق وساعات العمل.
- نموذج طلب موعد مع التحقق من الحقول والتاريخ.
- تصميم يعمل على الهاتف والحاسوب وإمكانية تنقل إلى أقسام الصفحة.

## حدود النسخة

هذه واجهة تجريبية فقط. النموذج لا يرسل البيانات ولا يخزنها، والموعد لا يتأكد تلقائيًا. لا تدخل معلومات صحية في النموذج. يلزم ربط خدمة خلفية آمنة والتحقق من بيانات العيادة قبل الاستخدام الفعلي.

يمكن نشر الصفحة عبر GitHub Pages من الفرع `main` ومجلد الجذر.
